# P0 待办事项

## 平台化改造计划（大方向）

> 目标：从单人课程站 → 多贡献者课程平台，每位贡献者有独立空间、自定义定价、AI 辅助创作，平台抽佣 10%。

### 阶段一：最小验证（备案前，1-2 周）

在现有 VitePress 架构上不做大改动，手动跑通商业逻辑：

- [ ] 新增「贡献者申请页」，贡献者填表 + 一次性付费买断开课权限
- [ ] 手动给付费贡献者开通权限（暂不自动化）
- [ ] 贡献者提交材料/灵感 → 后台用 AI 生成 Markdown 课程 → 手动发布到其独立路径
- [ ] 验证：贡献者愿不愿意付费、用户愿不愿意买贡献者的课

### 阶段二：技术重写（备案后）

VitePress 是静态站，无法支持动态多用户，需整体迁移到 **Next.js**：

- [ ] 数据库选型（课程、用户、订单、分账记录）
- [ ] 每位贡献者独立空间（独立 URL、主页、课程列表）
- [ ] 贡献者后台（发布课程、查看收益、上传素材）
- [ ] AI 创作工具：一键生成模式（粘贴材料 → 生成完整章节）
- [ ] AI 创作工具：多轮对话模式（类 ChatGPT 协作编辑）
- [ ] 动态定价系统（每门课独立定价）
- [ ] 平台抽佣分账（ZPAY 回调后 9:1 拆分，账务记录）
- [ ] 贡献者计划购买（一次性买断，解锁开课权限）

## 迁移至腾讯云 + ICP 备案攻略

> 目标：解决微信内打开显示"危险网站"的问题，完成合规经营。
> 预计总耗时：操作 ~2 小时 + 等待审核 15-25 个工作日。

---

### 第一步：购买域名（10 分钟）

1. 前往 [腾讯云域名注册](https://dnspod.cloud.tencent.com/)
2. 搜索你想要的域名，推荐后缀：`.cn`（备案最快）或 `.com`
3. 付款，完成实名认证（身份证）
4. 备案期间域名先解析到临时页或保持当前 SealOS 地址

---

### 第二步：购买腾讯云轻量应用服务器（10 分钟）

1. 前往 [腾讯云轻量应用服务器](https://cloud.tencent.com/product/lighthouse)
2. 选择配置：**2核2G 4M带宽**，地域选**上海**或**北京**（大陆节点，备案必须）
3. 镜像选 **Ubuntu 22.04**
4. 费用参考：新用户约 ¥99-180/年
5. 购买后记录服务器公网 IP

---

### 第三步：申请 ICP 备案（30 分钟填表 + 等待）

1. 登录腾讯云控制台 → 搜索「网站备案」
2. 点击「开始备案」→ 选择「个人备案」
3. 填写信息：
   - 主办者姓名、身份证号、手机号
   - 网站名称（如：学会用AI）
   - 网站域名（你购买的域名）
   - 服务器 IP（第二步购买的腾讯云服务器）
4. 上传身份证正反面照片
5. 按提示完成人脸识别或幕布拍照（腾讯云会邮寄幕布或提供二维码）
6. 提交后等待初审（1-3个工作日）→ 管局审核（15-20个工作日）
7. 收到备案号后，网站底部需展示备案号（如：京ICP备XXXXXXXX号）

> 注意：备案期间网站不能对外提供服务（或只能展示"网站备案中"页面）

---

### 第四步：服务器环境配置（30 分钟）

SSH 登录服务器后执行：

```bash
# 安装 Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 PM2
sudo npm install -g pm2

# 安装 Nginx
sudo apt-get install -y nginx

# 安装 Certbot（SSL 证书）
sudo apt-get install -y certbot python3-certbot-nginx
```

---

### 第五步：部署项目（30 分钟）

有两种方式，推荐方式 A：

**方式 A：保持 GitHub Actions 自动构建（推荐）**

1. 服务器安装 Docker：
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
2. 在服务器上拉取并运行镜像：
   ```bash
   docker pull jingyuanzzz/learn-with-ai:latest
   docker run -d --name lwa --restart always \
     -p 3000:80 \
     -e SEALOS=1 \
     -e AUTH_SECRET=你的密钥 \
     -e ZPAY_PID=你的PID \
     -e ZPAY_KEY=你的KEY \
     jingyuanzzz/learn-with-ai:latest
   ```
3. 配置 Nginx 反代到 3000 端口（见下方配置）

**方式 B：直接在服务器 clone 代码构建**

```bash
git clone https://github.com/ntu-zjy/learn-with-ai.git
cd learn-with-ai
npm install
npm run build
node server/index.mjs
```

---

### 第六步：配置 Nginx + SSL（20 分钟）

```nginx
# /etc/nginx/sites-available/learnwithai
server {
    listen 80;
    server_name 你的域名.cn;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

申请 SSL 证书：
```bash
sudo certbot --nginx -d 你的域名.cn
# 按提示操作，自动续期
```

---

### 第七步：DNS 解析 + 切换（5 分钟）

1. 在腾讯云 DNSPod 添加 A 记录：
   - 主机记录：`@`
   - 记录值：服务器公网 IP
2. 等待 DNS 生效（通常 5-10 分钟）
3. 访问你的域名确认正常
4. SealOS 可以保留作为备用，或停止节省费用

---

### 第八步：备案号展示（备案通过后）

在网站底部添加备案号，编辑 `docs/.vitepress/theme/Layout.vue`：

```html
<footer class="site-footer">
  <a href="https://beian.miit.gov.cn/" target="_blank">京ICP备XXXXXXXX号</a>
</footer>
```
