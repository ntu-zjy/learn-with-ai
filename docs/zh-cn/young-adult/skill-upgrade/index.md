# AI 加速技能提升

> 学技能最怕“看了很多教程，却没有作品、没有反馈、没有复盘”。

AI 可以帮你把技能学习从“看内容”改成“做任务”：每周产出作品，每次拿反馈，每轮缩小差距。

<PaywallBlock title="技能提升完整课程" plan="进阶版或以上">

## 1. 技能提升三件事

| 任务 | 说明 |
| --- | --- |
| 明确能力模型 | 这项技能由哪些子能力构成 |
| 设计练习任务 | 每个子能力如何训练 |
| 建立反馈循环 | 谁来评价，按什么标准改 |

## 2. 能力拆解 Prompt

```text
我想在 8 周内提升【技能】。
我的当前水平是【描述水平】。
目标是【就业/考试/作品/项目】。

请帮我拆解：
1. 这项技能的 5 个核心子能力。
2. 每个子能力的入门标准和进阶标准。
3. 每周练习任务。
4. 每两周一个作品产出。
5. 评价标准和常见错误。
```

## 3. 项目驱动学习

不要只问“推荐课程”。更好的问题是：

```text
请为【技能】设计 3 个由易到难的小项目。
每个项目包括：
1. 项目目标
2. 需要用到的知识
3. 完成标准
4. 可展示成果
5. 如何让 AI 帮我检查质量
```

## 4. 反馈 Prompt

```text
这是我的练习作品：
【粘贴作品/链接/文字描述】

请按专业标准反馈：
1. 最明显的 3 个问题
2. 其中最应该先改的 1 个
3. 修改建议
4. 下一次练习任务
5. 如果我要用于求职，还差什么
```

## 本节练习

选择一个技能，生成 8 周项目式学习计划。删掉所有“看教程”式任务，替换成“做出一个东西”的任务。
