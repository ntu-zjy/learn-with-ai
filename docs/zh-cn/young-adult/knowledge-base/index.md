# 构建你的 AI 知识库

> 知识库不是资料仓库，而是你能反复调用的第二大脑。

很多人收藏了大量文章、PDF、课程笔记，却很少回看。AI 知识库的价值，是让这些资料变成可提问、可复盘、可生成行动的素材。

## 1. 先定义知识库用途

不要一上来就导入所有资料。先问自己：这个知识库服务什么目标？

| 目标 | 应该收什么 | 不该收什么 |
| --- | --- | --- |
| 考研 | 错题、笔记、真题解析 | 泛泛经验帖 |
| 求职 | 项目经历、岗位 JD、面试复盘 | 无关行业文章 |
| 论文 | 论文 PDF、阅读笔记、概念卡 | 没读过的论文堆积 |
| 技能提升 | 教程笔记、练习记录、项目复盘 | 收藏但不用的链接 |

## 2. 知识卡模板

```text
标题：
来源：
主题：
核心观点：
关键证据：
我的理解：
可以用在哪些场景：
下一步行动：
```

## 3. 整理 Prompt

```text
请把下面资料整理成知识卡。
要求：
1. 不要照抄原文。
2. 提炼 3 个核心观点。
3. 标出我可能误解的地方。
4. 生成 5 个以后可以追问的问题。
5. 给出一个可以实践的小任务。

资料：
【粘贴资料】
```

## 4. 每周知识库复盘

```text
这是我本周新增的知识卡：
【粘贴卡片标题和摘要】

请帮我：
1. 找出它们之间的共同主题。
2. 合并重复内容。
3. 生成一份本周学习总结。
4. 给出下周最值得继续深入的 3 个问题。
```

::: tip 原则
知识库的质量不取决于资料数量，而取决于你是否持续提问、整理和复用。
:::

## 本节练习

选 3 篇最近读过的文章或 3 份课堂笔记，整理成知识卡。然后问 AI："这 3 张卡之间有什么联系？"
