# 用 AI 做职业路径分析

> 职业规划不是让 AI 告诉你“适合什么”，而是让 AI 帮你把选择的证据摆清楚。

AI 可以帮你分析岗位、能力差距和路径选择，但最终判断必须结合你的价值观、资源和现实约束。

<PaywallBlock title="职业路径分析完整课程" plan="高级版或以上">

## 1. 职业选择四维度

| 维度 | 要问的问题 |
| --- | --- |
| 兴趣 | 我愿意长期研究这个领域吗？ |
| 能力 | 我已有能力和岗位要求差多少？ |
| 市场 | 这个方向的机会和风险是什么？ |
| 生活 | 它是否符合我的城市、收入、节奏需求？ |

## 2. 路径分析 Prompt

```text
请做我的职业路径分析师。

我的背景：
【学历、专业、经历、技能、城市、限制】

我在考虑的方向：
【方向 A、方向 B、方向 C】

请从以下维度对比：
1. 典型岗位和工作内容
2. 入门门槛
3. 我已有优势
4. 最大短板
5. 3 个月验证方法
6. 主要风险

请用表格输出，并给出你最建议我先验证的一个方向。
```

## 3. 不要只听结论

AI 的建议只能作为“假设”。你需要用真实行动验证：

- 访谈 3 个从业者。
- 分析 20 个岗位 JD。
- 做一个小项目或作品。
- 尝试投递或模拟面试。

## 4. 3 个月验证计划

```text
我想验证自己是否适合【职业方向】。
请帮我设计一个 12 周验证计划。
要求：
1. 每 2 周有一个可展示产出。
2. 包含岗位研究、技能学习、作品实践和反馈。
3. 设计退出条件：什么情况下说明不适合继续投入。
```

## 本节练习

选择 2 个你正在犹豫的职业方向，让 AI 生成对比表。然后找真实 JD 核对其中的岗位要求是否准确。
