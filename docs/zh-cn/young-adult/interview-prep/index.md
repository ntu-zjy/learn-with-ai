# AI 面试模拟与复盘

> 面试准备不是背标准答案，而是训练你在压力下讲清楚真实经历。

AI 可以扮演不同风格的面试官，连续追问你的项目、动机、能力和不足。

## 1. 面试模拟 Prompt

```text
请你扮演【岗位】面试官。
我会投递的岗位 JD 是：
【粘贴 JD】

我的简历经历是：
【粘贴简历】

请按真实面试方式进行：
1. 每次只问一个问题。
2. 先从自我介绍开始。
3. 根据我的回答继续追问。
4. 不要提前给标准答案。
5. 面试结束后再做整体反馈。
```

## 2. STAR 回答法

| 结构 | 要回答什么 |
| --- | --- |
| Situation | 当时背景是什么 |
| Task | 你负责什么目标 |
| Action | 你具体做了什么 |
| Result | 最后结果和证据是什么 |

## 3. 回答复盘 Prompt

```text
这是我刚才的面试回答：
【粘贴回答】

请从以下角度反馈：
1. 是否符合 STAR 结构？
2. 哪些地方太空泛？
3. 面试官可能继续追问什么？
4. 请给我一个更自然的表达版本。
5. 保留真实信息，不要编造结果。
```

## 4. 压力追问训练

```text
请对我的回答进行压力追问。
要求：
1. 连续追问 3 轮。
2. 每轮只针对一个漏洞。
3. 问题要像真实面试官，不要太友好。
4. 最后总结我最需要补的证据。
```

::: tip 训练建议
把 AI 的问题读出来并口头回答，再把录音转成文字复盘。面试能力不是写出来的，是说出来、改出来的。
:::

## 本节练习

用一个真实 JD 做 15 分钟模拟面试。结束后让 AI 输出“最危险的 3 个追问”，并为每个追问准备一个证据。
