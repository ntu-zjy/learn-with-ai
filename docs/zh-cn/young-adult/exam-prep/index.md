# AI 辅助考研备考全流程

> 考研不是拼“今天学了多久”，而是拼“薄弱点有没有被持续识别和修正”。

AI 不能替你背书、刷题、上考场，但它可以帮你建立一个更清醒的备考系统。

## 1. 备考系统的四个模块

| 模块 | AI 的作用 | 你的任务 |
| --- | --- | --- |
| 计划 | 拆阶段、排优先级 | 提供真实时间和目标 |
| 学习 | 解释难点、生成例题 | 主动练习 |
| 错题 | 归类错因、生成变式 | 记录过程 |
| 复盘 | 调整下周计划 | 诚实反馈执行情况 |

## 2. 初始规划 Prompt

```text
请做我的考研备考规划师。

考试科目：
目标院校/专业：
当前基础：
距离考试时间：
每天可用时间：
最薄弱科目：

请输出：
1. 阶段划分。
2. 每个阶段的核心目标。
3. 每周必须完成的可检查产出。
4. 风险提醒。
5. 如果执行落后，如何降级计划。
```

## 3. 错题复盘 Prompt

```text
这是我本周的错题记录：
【粘贴错题、错误答案、正确解析】

请帮我：
1. 按知识点和错误类型分类。
2. 找出最影响提分的 3 个问题。
3. 生成下周训练清单。
4. 每个问题配 1 道同类练习题。
```

## 4. 每月调整

每个月问 AI 一次：

```text
根据我这个月的完成情况和错题分布，请判断：
1. 哪个科目投入过多但收益低？
2. 哪个薄弱点被忽略？
3. 下个月计划应该增加、减少或暂停哪些任务？
```
