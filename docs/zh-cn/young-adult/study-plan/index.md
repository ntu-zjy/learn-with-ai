# 用 AI 制定学习计划

> 学习计划失败，通常不是因为你不努力，而是因为计划没有反馈机制。

AI 很适合做学习规划师，但前提是你给它足够真实的信息：目标、时间、基础、薄弱点和可执行产出。

## 1. 为什么普通计划容易失败

普通计划常常长这样：

```text
每天背单词、刷题、看网课。
```

它的问题是：

- 没有优先级，不知道先补什么。
- 没有产出，不知道每天完成到什么程度。
- 没有复盘，不知道计划是否需要调整。

## 2. AI 学习计划模板

```text
请你做我的学习规划师。

我的目标：【例如 90 天后参加考试/完成一门课程/准备面试】
我的基础：【已经会什么，不会什么】
可用时间：【每天/每周能投入多久】
最大困难：【拖延、看不懂、缺练习、缺反馈等】
评价标准：【分数、作品、面试表现、论文笔记等】

请输出：
1. 目标拆解：分成 3-5 个能力模块。
2. 30 天计划：按周安排，不要按天塞太满。
3. 每周产出：必须能被检查。
4. 复盘问题：每周末问自己 5 个问题。
5. 风险预案：如果落后 3 天，如何调整。
```

## 3. 计划要有三层

| 层级 | 作用 | 示例 |
| --- | --- | --- |
| 月计划 | 定方向 | 30 天完成考研英语阅读基础训练 |
| 周计划 | 排重点 | 本周专攻长难句和错题复盘 |
| 日任务 | 能执行 | 做 2 篇阅读，复盘 4 道错题 |

::: tip 计划不要太满
一个好计划应该留出 20%-30% 的缓冲。没有缓冲的计划，只要一天失败，就容易全盘放弃。
:::

## 4. 每周复盘 Prompt

```text
这是我本周的学习记录：
【粘贴任务完成情况、错题、困惑】

请帮我复盘：
1. 本周真正完成了什么？
2. 最大阻碍是什么？
3. 哪些任务应该删除或简化？
4. 下周最重要的 3 件事是什么？
5. 请把下周计划调整成每天不超过 2 个核心任务。
```
