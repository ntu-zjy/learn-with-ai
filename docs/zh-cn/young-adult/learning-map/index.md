# 青年学习路线图

> 青年阶段的核心问题不是“我要不要用 AI”，而是“我能不能用 AI 把长期目标拆成每天可执行的行动”。

这条路线适合大学生、考研备考者、论文阅读者、求职者和刚进入职场的人。它把 AI 当作学习规划师、资料助理、模拟面试官和职业复盘教练。

## 30 天建议

| 周次 | 目标 | 产出 |
| --- | --- | --- |
| 第 1 周 | 学会写清任务 | 3 条个人常用 Prompt |
| 第 2 周 | 拆解一个长期目标 | 30 天学习计划 |
| 第 3 周 | 完成一个专项任务 | 论文笔记、简历或备考计划 |
| 第 4 周 | 复盘并迭代 | 一套个人 AI 学习工作流 |

::: tip 学习建议
不要同时追太多方向。先选一个真实目标：考研、求职、论文、技能升级，围绕它跑完整个“计划-执行-反馈-复盘”循环。
:::
