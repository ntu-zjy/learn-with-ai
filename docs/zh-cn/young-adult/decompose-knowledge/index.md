# 拆解复杂知识的 AI 方法

> 复杂知识并不可怕，可怕的是一上来就读完整本书、整门课、整篇论文。

这一节训练你把"我看不懂"变成"我知道自己卡在哪一层"。

## 1. 五层拆解法

| 层级 | 要问的问题 | 产出 |
| --- | --- | --- |
| 背景 | 这个知识解决什么问题？ | 一句话动机 |
| 概念 | 有哪些必须懂的关键词？ | 关键词表 |
| 机制 | 它是怎么工作的？ | 流程图或步骤 |
| 例子 | 最小可理解例子是什么？ | 一个具体案例 |
| 练习 | 如何检查我是否学会？ | 3 道小题或任务 |

## 2. 拆解 Prompt

```text
我正在学习【复杂主题】。
请不要直接给一篇百科式解释。

请按五层拆解：
1. 它要解决的核心问题是什么？
2. 必须先懂的 8 个关键词是什么？
3. 它的工作流程可以分成哪 5 步？
4. 给一个最简单的例子。
5. 设计 3 个检查理解的小练习。

请标出我最可能卡住的地方，并给出学习顺序。
```

## 3. 从"听懂"到"会用"

学完解释后，继续追问：

```text
请不要继续讲新知识。
请用 5 个问题测试我是否真的理解。
我回答后，你再指出我的误区。
```

## 4. 常见误区

- **只收藏解释**：看懂解释不等于掌握。
- **跳过基础概念**：关键词不清楚，后面越学越乱。
- **没有输出**：必须写总结、做题或讲给别人听。

## 本节练习

选一个你正在学习的难主题，生成一份"五层拆解表"。然后只学习第一层和第二层，不急着往后冲。
