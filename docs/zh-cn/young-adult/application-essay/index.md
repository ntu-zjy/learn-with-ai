# AI 助力申请文书

> 好文书不是华丽辞藻，而是让评审看见：你是谁、你做过什么、你为什么适合这个方向。

AI 可以帮你梳理经历和修改表达，但不能替你制造经历或夸大事实。

<PaywallBlock title="申请文书完整课程" plan="进阶版或以上">

## 1. 先挖经历，不先写文章

```text
请做我的申请文书教练。
先不要帮我写文书。
请通过连续提问，帮我挖掘 3 段最能体现能力和动机的经历。
每次只问一个问题，等我回答后再继续。
```

## 2. 经历筛选表

| 经历 | 展示能力 | 证据强度 | 和申请方向关系 | 是否值得写 |
| --- | --- | --- | --- | --- |
| 项目/竞赛/课程/实习 | 研究、领导、沟通、解决问题 | 数据、结果、反馈 | 强/中/弱 | 是/否 |

## 3. 文书结构 Prompt

```text
这是我的申请方向和经历素材：
【粘贴信息】

请帮我设计文书结构。
要求：
1. 不要替我写完整成稿。
2. 给出开头、主体、结尾的功能。
3. 判断每段应该放哪段经历。
4. 标出哪些地方需要补充真实细节。
5. 避免空泛形容词和夸大表达。
```

## 4. 修改 Prompt

```text
请修改我的文书草稿。
要求：
1. 保留我的真实经历和语气。
2. 删除空话、套话和过度包装。
3. 标出逻辑不清的句子。
4. 给出修改理由，而不是只给改写结果。

草稿：
【粘贴文书】
```

::: warning 真实性原则
文书最怕“看起来完美但不像真人”。AI 的润色应该服务于真实表达，而不是把你包装成不存在的人。
:::

## 本节练习

列出 5 段经历，让 AI 帮你筛选最值得写的 2 段。然后只让 AI 设计结构，不让它直接成稿。
