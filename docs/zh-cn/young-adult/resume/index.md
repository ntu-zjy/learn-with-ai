# AI 打造完美简历

> 简历不是经历清单，而是你和目标岗位之间的匹配证据。

AI 最适合帮你做两件事：读懂岗位 JD，以及把你的经历改写成"有动作、有结果、有证据"的表达。

## 1. 先分析岗位，再改简历

```text
请分析下面这个岗位 JD。
输出：
1. 核心职责
2. 必备能力
3. 加分能力
4. 简历中应该重点体现的关键词
5. 面试可能追问的问题

岗位 JD：
【粘贴 JD】
```

## 2. 经历改写公式

推荐使用：

```text
动词 + 任务 + 方法 + 结果 + 证据
```

普通写法：

```text
负责社团公众号运营。
```

更好的写法：

```text
独立策划并运营社团公众号内容，建立选题表和发布节奏，3 个月内发布 24 篇推文，平均阅读量提升 40%。
```

## 3. 简历优化 Prompt

```text
请基于目标岗位优化我的简历经历。

目标岗位 JD：
【粘贴 JD】

我的经历：
【粘贴经历】

要求：
1. 不要编造经历和数据。
2. 只在我提供的信息基础上改写。
3. 每条经历尽量体现动作、方法、结果。
4. 标出缺少数据或证据的地方。
5. 输出 3 个版本：保守版、标准版、突出成果版。
```

## 4. 风险检查

让 AI 做一轮"面试官检查"：

```text
请像面试官一样审查我的简历。
找出：
1. 可能被追问但我没准备好的点。
2. 表达夸大或证据不足的点。
3. 与岗位匹配度低的内容。
4. 建议删除或压缩的内容。
```

## 本节练习

找一个真实岗位 JD，选择一段项目经历，用"动词 + 任务 + 方法 + 结果 + 证据"改写。再让 AI 生成 5 个面试追问。
