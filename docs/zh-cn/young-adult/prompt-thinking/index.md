# Prompt 思维精讲

> 学会提问，是 AI 时代最值钱的能力。但真正的 Prompt 思维，不是把话写得复杂，而是把任务说得可执行。

大多数人用 AI 的方式是“发指令”：告诉 AI 做什么。  
会用 Prompt 的人是在“建对话”：让 AI 理解你的处境、目标、限制和评价标准。

### 1. 身份背景

告诉 AI 你是谁，你所处的阶段是什么。

| 普通 | 有背景 |
| --- | --- |
| 帮我分析这个行业 | 我是应届生，想判断新能源行业是否适合做产品经理，请从岗位机会角度分析 |
| 帮我写学习计划 | 我还有 60 天准备考试，每天 3 小时，薄弱点是阅读和错题复盘 |

### 2. 具体目标

不要只说“了解一下”，要说清楚“最后要能做什么”。

```text
我不是想泛泛了解论文，而是想判断这篇论文的研究问题、方法和局限，最后写出 800 字读书笔记。
```

### 3. 约束条件

约束越清楚，AI 越不会跑偏：

- 时间：30 分钟、7 天、一个月。
- 风格：正式、口语、面试表达、学术表达。
- 边界：不要替我写全文、不要编造事实、只基于我提供的材料。

### 4. 输出格式

AI 默认会写一大段话。你可以指定输出形态：

```text
请用表格输出，列为：问题、原因、修改建议、优先级。
```

### 5. 反馈方式

真正的高质量结果通常来自第二轮、第三轮：

```text
这版方向对，但太泛。请保留第 2 点，删掉空话，增加一个可执行例子。
```

## 一个完整模板

```text
你将扮演【角色】。
我的背景是【身份、基础、限制】。
我的目标是【具体产出或能力】。
请在【约束条件】下，输出【格式】。

回答前请先判断：这个任务最容易出错的地方是什么。
回答后请给我一个下一轮可以继续追问的问题。
```

## 本节练习

把你最近一个真实任务写成两版 Prompt：

1. 只写一句普通提问。
2. 用“五要素模板”重写。

对比 AI 两次回答，记录哪一版更贴近你的真实需求。
