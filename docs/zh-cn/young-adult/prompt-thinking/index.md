# Prompt 思维精讲

> 学会提问，是 AI 时代最值钱的能力。

大多数人用 AI 的方式是"发指令"——告诉 AI 做什么。

会用 Prompt 的人是"建对话"——让 AI 真正理解你的处境、目标和约束，然后给出专属于你的答案。

这一节，我们从底层逻辑讲清楚 Prompt 到底是什么，以及为什么同样一件事，两个人问出的结果天差地别。

## Prompt 的五个构成要素

一条好的 Prompt，通常包含以下五个要素（不是每条都需要全部包含，但越完整效果越好）：

<StepBar :steps="['身份背景', '具体目标', '约束条件', '输出格式', '示例参考']" />

### 1. 身份背景（Who are you）

告诉 AI 你是谁，你所处的处境是什么。

| 普通 | 有背景 |
|------|------|
| 帮我分析这个行业 | 我是一个有5年销售经验、打算转行做B端SaaS创业的人，请帮我分析医疗信息化行业 |
| 帮我写一篇文章 | 我是一个公众号作者，读者是25-35岁的职场人，我需要写一篇关于时间管理的推文 |

### 2. 具体目标（What you need）

不是"帮我了解X"，而是"帮我解决Y问题"或"帮我得到Z结果"。

### 3. 约束条件（Constraints）

时间、字数、风格、禁用词、格式要求……约束越清晰，AI 越不会"发散"。

### 4. 输出格式（Output format）

要表格？要列表？要代码？要分析报告？明确说出来。

### 5. 示例参考（Examples）

给出一个期望的输出样例，AI 会自动对齐风格。

## 一个完整的 Prompt 模板

```
[身份]：我是___，目前面临的情况是___
[目标]：我需要___
[约束]：___（字数/风格/格式/禁用词等）
[示例]：类似这样的效果：___（可选）
```

## 三种高阶 Prompt 技巧

### 角色扮演法

让 AI 扮演一个特定角色，它的回答质量会大幅提升。

```
你是一位在头部咨询公司工作了10年的商业分析师，
擅长快速拆解行业格局和竞争壁垒。
请用你的视角分析……
```

### 链式思考法

让 AI 先拆解问题，再给出答案，适合复杂决策。

```
请先分解这道题的解题步骤，
列出你的思考过程，
然后再给出最终答案。
```

### 迭代优化法

不要指望一次就得到完美输出，用反馈来持续改进。

```
第一轮：[基础 Prompt]
第二轮：好，但[具体不足]，请在保持[好的部分]的前提下改进。
第三轮：更好了，只需要调整[最后细节]。
```
