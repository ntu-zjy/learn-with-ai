# 用 AI 精读论文

> 读论文的目标不是把每句话翻译出来，而是看懂作者想解决什么问题、怎么证明、哪里仍然有限。

AI 可以降低论文阅读门槛，但你仍然需要回到原文判断证据是否成立。

<PaywallBlock title="论文精读完整课程" plan="进阶版或以上">

## 1. 论文精读五问

| 问题 | 目的 |
| --- | --- |
| 作者要解决什么问题？ | 抓研究动机 |
| 过去方法哪里不够？ | 看创新来源 |
| 作者提出了什么方法？ | 理解核心机制 |
| 实验如何证明有效？ | 判断证据强度 |
| 还有什么局限？ | 形成批判性思考 |

## 2. 摘要初读 Prompt

```text
我会给你一篇论文的标题和摘要。
请不要夸大论文贡献。
请按以下结构解释：
1. 研究问题
2. 方法一句话
3. 主要贡献
4. 我读全文前需要先懂的关键词
5. 可能的局限

标题和摘要：
【粘贴内容】
```

## 3. 方法部分精读 Prompt

```text
请帮我精读论文的方法部分。
要求：
1. 把方法拆成步骤。
2. 解释每一步解决什么问题。
3. 标出我必须回到原文看的公式、图或表。
4. 用一个简单例子说明方法如何运行。

方法部分：
【粘贴内容】
```

## 4. 读书笔记模板

```text
论文标题：
一句话总结：
研究问题：
核心方法：
关键证据：
我真正理解的部分：
我还不理解的部分：
可以借鉴到我的研究/项目中的点：
```

::: warning 学术诚信
AI 可以帮你解释和整理，但引用、结论和批判必须回到原文。不要引用 AI 编造的论文、数据或作者观点。
:::

## 本节练习

选择一篇论文，只读标题、摘要和结论。用 AI 生成“五问笔记”，再回到原文验证 AI 的总结是否准确。
