# 用 AI 精读论文

> 读论文的目标不是把每句话翻译出来，而是看懂作者想解决什么问题、怎么证明、哪里仍然有限。

AI 可以降低论文阅读门槛，但你仍然需要回到原文判断证据是否成立。

## 1. 论文精读五问

| 问题 | 目的 |
| --- | --- |
| 作者要解决什么问题？ | 抓研究动机 |
| 过去方法哪里不够？ | 看创新来源 |
| 作者提出了什么方法？ | 理解核心机制 |
| 实验如何证明有效？ | 判断证据强度 |
| 还有什么局限？ | 形成批判性思考 |

## 2. 摘要初读 Prompt

```text
我会给你一篇论文的标题和摘要。
请不要夸大论文贡献。
请按以下结构解释：
1. 研究问题
2. 方法一句话
3. 主要贡献
4. 我读全文前需要先懂的关键词
5. 可能的局限

标题和摘要：
【粘贴内容】
```

## 3. 方法部分精读 Prompt

```text
请帮我精读论文的方法部分。
要求：
1. 把方法拆成步骤。
2. 解释每一步解决什么问题。
3. 标出我必须回到原文看的公式、图或表。
4. 用一个简单例子说明方法如何运行。

方法部分：
【粘贴内容】
```

## 4. 读书笔记模板

```text
论文标题：
一句话总结：
研究问题：
核心方法：
关键证据：
我真正理解的部分：
我还不理解的部分：
可以借鉴到我的研究/项目中的点：
```

::: warning 学术诚信
AI 可以帮你解释和整理，但引用、结论和批判必须回到原文。不要引用 AI 编造的论文、数据或作者观点。
:::

## 场景二：考研英语长难句辅助

如果你正在备考研究生，可以用 AI 来拆解长难句，提升英语阅读速度。

**适用场景**：遇到读不懂的英文句子，不确定主干在哪、从句如何嵌套。

**即用 Prompt：**

```
请帮我拆解这个英文长难句：

[粘贴英文句子]

要求：
1. 标注句子主干（主语 + 谓语 + 宾语）
2. 标出所有从句，说明每个从句的类型（定语/状语/宾语从句）
3. 用中文解释整句的意思
4. 告诉我这类句型结构的阅读技巧
```

**注意**：AI 拆句子有时会出错，建议遇到有把握的句子自己先尝试，再用 AI 对比验证，而不是直接依赖 AI。
