# AI 辅助课后复习系统

> 真正提高成绩的不是“学了多少”，而是“错过的东西有没有被重新看见”。

这一节把 AI 从“临时问答工具”升级为“复习系统”：它帮你整理错题、识别薄弱点、安排下一轮训练。

<PaywallBlock title="课后复习系统完整课程" plan="进阶版或以上">

## 1. 复习系统的三个文件夹

建议建立三个固定文档：

| 文件夹 | 放什么 | AI 做什么 |
| --- | --- | --- |
| 错题库 | 错题、错误答案、正确答案 | 归类错因 |
| 知识卡 | 概念、公式、易混点 | 生成自测卡 |
| 周复盘 | 本周问题和下周计划 | 找出重复错误 |

## 2. 错题录入模板

```text
请把下面错题整理成错题卡。

科目：
题目：
我的答案：
正确答案：
老师/参考解析：

请输出：
1. 考察知识点
2. 我的错误类型
3. 一句话提醒
4. 一道同类变式题
```

## 3. 周复盘 Prompt

```text
这是我本周整理的错题卡：
【粘贴 5-10 张错题卡】

请帮我做周复盘：
1. 找出出现次数最多的 3 类错误。
2. 判断哪些是概念问题，哪些是习惯问题。
3. 给我下周每天 20 分钟的复习安排。
4. 每天安排一个可检查的小产出。
```

## 4. 复习系统不要太复杂

最容易失败的复习系统，是一开始就做得太精致。你只需要坚持三个动作：

1. 当天错题当天录入。
2. 每周固定复盘一次。
3. 每次只训练最重要的一个薄弱点。

## 本节练习

从最近一周作业或试卷中选 5 道错题，生成错题卡。让 AI 找出共同错因，并制定一个 3 天微训练计划。
