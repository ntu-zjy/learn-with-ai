# AI 帮你做项目研究

> 项目研究不是“复制资料做 PPT”，而是围绕一个问题，收集证据、形成观点、清楚表达。

AI 可以帮你从“我想做个项目”走到“我有一个可展示的研究作品”，但它不能替你观察、判断和表达真实体验。

<PaywallBlock title="项目研究完整课程" plan="AI 实践者或以上">

## 1. 从主题变成问题

普通主题太大，例如：

```text
人工智能的发展
```

研究问题更具体：

```text
AI 翻译工具会怎样影响初中生学习英语的方式？
```

好的研究问题通常满足：

- 具体到一个人群或场景。
- 能收集资料或做小调查。
- 最后能形成自己的观点。

## 2. 选题 Prompt

```text
我是一名【年级】学生，需要做一个项目研究。
我感兴趣的方向是【方向】。

请帮我生成 10 个适合学生完成的研究问题。
要求：
1. 每个问题都要具体，不能太大。
2. 标出需要收集哪些资料。
3. 标出适合用问卷、访谈还是观察。
4. 给出难度评分 1-5。
```

## 3. 研究流程

| 步骤 | 任务 | 产出 |
| --- | --- | --- |
| 选题 | 把兴趣变成问题 | 研究问题 |
| 查资料 | 找可靠资料和案例 | 资料卡片 |
| 小调查 | 问 5-10 个真实对象 | 调查记录 |
| 分析 | 找共同点和差异 | 观点提纲 |
| 展示 | 写报告或做 PPT | 最终作品 |

## 4. 资料整理 Prompt

```text
请把下面资料整理成研究卡片。
每张卡片包括：
1. 核心信息
2. 这条信息支持什么观点
3. 是否需要进一步核验
4. 可以放在报告哪个部分

资料：
【粘贴资料】
```

::: warning 资料核验
项目研究里，AI 生成的事实和案例都要核验来源。能用真实调查、教材资料或官方页面时，不要只引用 AI 的说法。
:::

## 本节练习

选择一个你感兴趣的主题，让 AI 帮你生成 10 个研究问题。选其中一个，完成“研究问题、资料来源、调查对象、最终展示形式”四项规划。
