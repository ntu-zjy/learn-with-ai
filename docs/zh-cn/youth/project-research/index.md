# AI 帮你做项目研究

> 这类任务看起来复杂，但用 AI 可以系统拆解。

比如你的历史老师要求写一篇 1000 字的小论文，题目自选，或者你需要做一个课堂展示 PPT。这类任务的难点不是”不会写”，而是不知道从哪里切入、怎么找角度、怎么把资料整理成自己的观点。

AI 可以帮你从”我有一个大方向”走到”我有一个清晰的研究问题和可展示的作品”，但它不能替你观察、判断和表达真实体验。

<PaywallBlock title="项目研究完整课程" plan="AI 实践者或以上">

## 1. 从主题变成问题

普通主题太大，例如：

```text
人工智能的发展
```

研究问题更具体：

```text
AI 翻译工具会怎样影响初中生学习英语的方式？
```

好的研究问题通常满足：

- 具体到一个人群或场景。
- 能收集资料或做小调查。
- 最后能形成自己的观点。

## 2. 选题 Prompt

```text
我是一名【年级】学生，需要做一个项目研究。
我感兴趣的方向是【方向】。

请帮我生成 10 个适合学生完成的研究问题。
要求：
1. 每个问题都要具体，不能太大。
2. 标出需要收集哪些资料。
3. 标出适合用问卷、访谈还是观察。
4. 给出难度评分 1-5。
```

## 3. 研究流程

| 步骤 | 任务 | 产出 |
| --- | --- | --- |
| 选题 | 把兴趣变成问题 | 研究问题 |
| 查资料 | 找可靠资料和案例 | 资料卡片 |
| 小调查 | 问 5-10 个真实对象 | 调查记录 |
| 分析 | 找共同点和差异 | 观点提纲 |
| 展示 | 写报告或做 PPT | 最终作品 |

## 4. 资料整理 Prompt

```text
请把下面资料整理成研究卡片。
每张卡片包括：
1. 核心信息
2. 这条信息支持什么观点
3. 是否需要进一步核验
4. 可以放在报告哪个部分

资料：
【粘贴资料】
```

::: warning 资料核验
项目研究里，AI 生成的事实和案例都要核验来源。能用真实调查、教材资料或官方页面时，不要只引用 AI 的说法。
:::

## 5. 完整示例：历史小论文《丝绸之路》

假设历史老师要求写一篇 1000 字小论文，题目自选。以下是用 AI 把”确定问题→找角度→收集资料→整理框架→自己写报告”这个流程落地的过程：

**第一步：把大主题变成具体问题**

```
我要写一篇关于丝绸之路的历史小论文，1000字，题目自选。
帮我生成 5 个有角度的研究问题，每个问题要具体、有观点，不能只是描述事实。
```

AI 可能返回：
- 丝绸之路上的贸易为什么能持续数百年而不中断？
- 香料和丝绸哪个对东西方文化交流影响更大？
- ……

选一个你感兴趣的，这就是你的论文角度。

**第二步：让 AI 帮你整理资料框架**

确定问题后，把你收集到的资料（课本内容、老师讲的要点）粘给 AI：

```
我的论文问题是：丝绸之路上的贸易为什么能持续数百年？
以下是我收集的资料，帮我整理成论文提纲，分成”引言→论据1→论据2→结论”四部分：

【粘贴资料】
```

**第三步：自己写，让 AI 只做框架不写内容**

拿到提纲后，按照框架自己写每一段。写完后让 AI 检查逻辑是否通顺，而不是让它帮你写整篇。

::: warning 关键原则
论文的观点和表达必须是你自己的。AI 帮你找角度、整理结构，但每一句话都要自己写。
:::

## 本节练习

选择一个你感兴趣的主题，让 AI 帮你生成 10 个研究问题。选其中一个，完成”研究问题、资料来源、调查对象、最终展示形式”四项规划。
