# 用 AI 背单词记知识

> 记忆不是把内容看很多遍，而是在快忘的时候把它主动提取出来。

AI 很适合做记忆教练：它能帮你生成例句、设计小测、根据错误调整复习节奏。

<PaywallBlock title="记忆训练完整课程" plan="基础版或以上">

## 1. 为什么死记硬背效率低

只看单词表或知识点清单，有两个问题：

- **缺少语境**：知道中文意思，不代表会用。
- **缺少提取**：看起来熟悉，不代表能想起来。

更好的记忆方式是：语境理解 + 主动回忆 + 间隔复习。

## 2. 单词学习 Prompt

```text
请你做我的英语单词教练。
我要记住这些单词：
【粘贴单词列表】

请为每个单词生成：
1. 一个适合初中/高中水平的英文例句。
2. 一个容易记住的联想。
3. 一个填空题。
4. 一个容易混淆的近义词或反义词。

先不要一次性给太多，每次给 5 个。
```

## 3. 知识点记忆 Prompt

```text
我正在背诵【知识主题】。
请把下面内容整理成“问题-答案”卡片。

要求：
1. 每张卡片只考一个知识点。
2. 问题要能逼我回忆，而不是让我机械填空。
3. 答案控制在 3 句话以内。
4. 最后给我一个 7 天复习安排。

材料：
【粘贴课本或笔记内容】
```

## 4. 7 天复习法

| 时间 | 任务 |
| --- | --- |
| 第 1 天 | 学新内容，生成卡片 |
| 第 2 天 | 不看答案自测 |
| 第 4 天 | 只复习错卡 |
| 第 7 天 | 混合测试，加入新例题 |

::: tip 关键动作
每次复习都要先自己答，再看答案。AI 的解释越好，也不能替代你的主动回忆。
:::

## 本节练习

选择 10 个单词或 8 个知识点，让 AI 生成卡片。第二天把不会的卡片标出来，再让 AI 只针对错卡生成新例子。
