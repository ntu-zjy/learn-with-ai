# 用 AI 攻克数学难题

> 数学学习最怕"答案看懂了，换题又不会"。这一节训练的是解题过程，而不是答案搬运。

AI 讲题很快，但如果你只看它的完整解析，很容易产生错觉：好像会了，其实只是看懂了别人怎么做。

## 1. 不要直接要解析

普通问法：

```text
这道题怎么做？
```

学习型问法：

```text
请不要直接给我完整答案。
你先帮我判断这道题考察什么知识点，再给我第一步提示。
我每完成一步，你再判断我是否正确。
```

## 2. 数学题四步拆解

| 步骤 | 要解决的问题 | AI 的作用 |
| --- | --- | --- |
| 读题 | 题目给了什么、求什么 | 帮你标出条件和目标 |
| 建模 | 用什么公式、图形或方程 | 提醒可能的知识点 |
| 计算 | 每一步是否合理 | 检查推导和算错 |
| 复盘 | 为什么会错 | 归类错因并安排同类题 |

## 3. 分步陪练 Prompt

```text
你是一位数学陪练老师。
请按"提示模式"帮助我做题。

规则：
1. 不要直接给最终答案。
2. 先判断题型和关键知识点。
3. 每次只给一个提示。
4. 我回答后，你判断对错，并解释原因。
5. 如果我连续两次卡住，再给更具体的提示。

题目：
【粘贴题目】
```

## 4. 错因分类

做完后，让 AI 帮你归类错因：

```text
这是我的解题过程和错误答案：
【粘贴过程】

请帮我判断错误属于哪一类：
- 概念没懂
- 读题漏条件
- 方法选择错
- 计算失误
- 步骤表达不清

请给我 2 道同类型小练习。
```

## 可直接复制的 Prompt 模板

**数学解题陪练 Prompt：**

```
我在做这道题：[粘贴题目]

我的解题过程是：[写出你的步骤，哪怕是错的]

我在第[X]步卡住了 / 我的答案是[Y]但好像不对

请告诉我哪里错了或者哪里的思路有问题，不要直接给我正确答案，让我自己重新做一遍
```

**追问模板（AI解释后还是不懂时）：**

```
你刚才说的第[X]步我还是不理解，能不能换一种更简单的方式解释？比如用一个生活中的例子？
```
