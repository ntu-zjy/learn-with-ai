# 青少年学习路线图

> 青少年学 AI，最重要的不是“让 AI 帮我做完”，而是“让 AI 帮我看见自己哪里还不会”。

这条路线适合学生、家长和老师一起使用。目标是把 AI 变成学习教练：它可以提问、讲解、批改、出题、复盘，但不替学生承担思考。

::: warning 家长和老师请注意
AI 可以帮助学生理解和修改，但不应该直接代写作业、替代考试训练或绕过老师要求。最好的监督方式不是禁止使用，而是要求学生保留“提问记录、修改记录和复盘记录”。
:::

## 每周学习节奏

建议每周只选一个真实任务，不要同时开太多工具。

1. **周一：提出问题**  
   把本周最难的一道题、一篇作文或一个知识点写清楚。

2. **周二到周四：AI 陪练**  
   让 AI 先提示思路，再让学生自己完成，再请 AI 反馈。

3. **周五：复盘整理**  
   记录本周最常犯的 3 个错误。

4. **周末：迁移练习**  
   换一道新题或一个新主题，检查方法是否能迁移。
