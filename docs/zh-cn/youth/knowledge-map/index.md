# 用 AI 制作知识脑图

> 脑图不是把笔记变漂亮，而是看清楚知识之间的关系。

当一个章节有很多概念时，学生最容易陷入"每个词都认识，但合起来不知道在讲什么"。知识脑图可以帮你建立结构。

## 1. 好脑图的标准

一张有效的知识脑图应该满足三点：

- **有中心问题**：不是"物理第三章"，而是"力如何改变物体运动？"
- **有层级关系**：概念、公式、题型不要混在同一层。
- **有连接词**：说明两个概念之间是因果、包含、对比还是应用。

## 2. 脑图生成 Prompt

```text
请把下面这段学习材料整理成知识脑图。

要求：
1. 先提炼一个中心问题。
2. 分成 3-5 个一级分支。
3. 每个分支下列出关键概念、例子和常见题型。
4. 用缩进文本输出，方便我手动画成脑图。
5. 标出最容易混淆的 3 组概念。

材料：
【粘贴课本/笔记/资料】
```

## 3. 从脑图到测验

脑图做完后，不要停在整理。继续让 AI 考你：

```text
请根据这张脑图设计 10 个自测问题。
要求从易到难，前 5 个考概念，后 5 个考应用。
我回答后你再批改。
```

## 4. 常见错误

| 错误 | 表现 | 修正 |
| --- | --- | --- |
| 分支太多 | 一张图像目录 | 一级分支控制在 5 个以内 |
| 只有名词 | 看不出关系 | 加上"导致、属于、用于"等连接词 |
| 不做测试 | 整理完就结束 | 用脑图生成自测题 |

## 本节练习

选一个最近学过的章节，把课本内容或笔记粘给 AI，生成一张缩进版脑图。然后让 AI 根据脑图出 5 道题，检查自己是否真的理解。
