# 用 AI 写更好的作文

> 这节课的目标不是让 AI 代写作文，而是让它像老师一样帮你发现：立意哪里浅、结构哪里乱、例子哪里空。

作文最难的地方，通常不是"不会写字"，而是看不见自己的问题。AI 的价值就在这里：它能快速给你一面镜子。

## 1. 先不要让 AI 写全文

很多学生会这样问：

```text
帮我写一篇关于坚持的作文。
```

这会得到一篇看似完整、但和你本人能力无关的作文。更好的方式是让 AI 先做诊断：

```text
我需要写一篇以"坚持"为主题的作文。
请先不要帮我写全文。
请你先问我 5 个问题，帮助我找到一个不俗套的立意和真实素材。
问题要一个一个问，等我回答后再继续。
```

## 2. 作文四层检查法

| 层级 | AI 可以怎么帮你 | 你要保留什么主动权 |
| --- | --- | --- |
| 立意 | 判断观点是否太空、太俗 | 最终观点必须自己确定 |
| 结构 | 检查开头、过渡、结尾是否顺 | 段落安排要自己理解 |
| 素材 | 提醒例子是否具体 | 真实经历要自己提供 |
| 语言 | 修改病句和啰嗦表达 | 不能把全文改成不像自己 |

## 3. 批改 Prompt

```text
你是一位严格但鼓励学生的语文老师。
请批改我的作文草稿。

要求：
1. 先用 1 句话判断这篇作文最主要的问题。
2. 按"立意、结构、素材、语言"四项分别打分，每项 10 分。
3. 每项只指出 1 个最值得修改的问题。
4. 不要直接重写全文，只给修改建议。
5. 最后给我一个 20 分钟内能完成的修改任务。

作文如下：
【粘贴作文】
```

## 4. 修改训练

拿到反馈后，不要让 AI 一次性重写全文。你可以这样追问：

```text
我想先修改"素材空泛"的问题。
请基于我原文第 2 段，追问我 3 个细节问题，帮助我把例子写具体。
```

## 本节练习

选择一篇自己写过的作文，完成三步：

1. 让 AI 按四层检查法批改。
2. 只选择一个问题修改。
3. 把修改前后两段放在一起，让 AI 判断是否真的变好。
