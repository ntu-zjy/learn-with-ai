# AI 学习 vs 普通搜索

> 搜索适合“找资料”，AI 适合“组织理解”。高手通常不是二选一，而是把两者组合起来。

如果你问：“什么是通货膨胀？”  
搜索会给你很多网页，AI 会给你一个解释。  
但真正的学习不是“看见解释”，而是能回答这些问题：

- 我能不能用自己的话讲出来？
- 我能不能举一个现实例子？
- 我能不能区分它和相近概念？
- 我能不能用它分析一个新问题？

这就是 AI 学习和普通搜索的分界线。

## 两者的能力边界

| 任务 | 更适合搜索 | 更适合 AI |
| --- | --- | --- |
| 查最新政策、价格、新闻 | 是 | 需要谨慎核验 |
| 找官方资料和原始出处 | 是 | 可辅助整理 |
| 解释一个概念 | 可以 | 是 |
| 制定学习计划 | 不擅长 | 是 |
| 批改你的答案 | 不擅长 | 是 |
| 追问薄弱点 | 不擅长 | 是 |
| 生成练习题并陪你复盘 | 不擅长 | 是 |

::: warning 注意
涉及最新信息、法律、医疗、金融决策时，AI 的回答必须回到可靠来源核验。AI 可以帮你分析，但不应该成为唯一依据。
:::

## 一个推荐流程

学习一个新主题时，可以用“三步法”：

1. **先搜索**：找到官方、教材、论文或权威媒体资料。
2. **再让 AI 整理**：请 AI 帮你提炼结构、解释难点、生成问题清单。
3. **最后让 AI 考你**：用小测验、错题复盘和迁移题检查是否真的学会。

示例 Prompt：

```text
我会先给你一段资料。请你不要补充未经资料支持的事实。
你的任务是：
1. 用初学者能懂的话总结核心观点。
2. 列出 5 个我必须理解的关键词。
3. 设计 3 个检查理解的问题。
4. 如果资料里有不确定或需要核验的地方，请标出来。

资料如下：
【粘贴资料】
```

## AI 更擅长的学习任务

AI 特别适合做三类事情：

- **把复杂知识拆小**：从章节、概念、例题、练习逐层拆。
- **把你的答案变清楚**：指出逻辑跳跃、表达含混、证据不足。
- **把学习变成循环**：计划、练习、反馈、复盘，再进入下一轮。

## 今日练习

选择一个你最近在学的概念，按下面流程试一次：

1. 用搜索找到一段你认为可靠的资料。
2. 把资料粘给 AI，让它生成关键词和测验题。
3. 不看资料回答测验题。
4. 让 AI 根据你的回答指出薄弱点。
