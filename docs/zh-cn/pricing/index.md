# 课程与定价

> 先免费学会基本方法，再按你的真实任务解锁专项课程。不要为了“学 AI”而买课，要为了一个具体学习目标开始。

<PricingPlans />

## 选择建议

- **只想体验方法**：从免费体验开始，完成 5 节入门课。
- **家里有学生**：优先看基础版，重点训练写作、数学、复习和项目研究。
- **正在考研或求职**：进阶版更适合，内容集中在计划、论文、简历、面试和职业成长。
- **关注商业和投资学习**：高级版更适合，重点是行业研究、财报阅读、机会扫描和个人 AI 系统。

::: warning 说明
投资相关课程只提供学习框架和分析方法，不构成任何投资建议。请结合可靠资料、专业意见和自身风险承受能力独立判断。
:::
