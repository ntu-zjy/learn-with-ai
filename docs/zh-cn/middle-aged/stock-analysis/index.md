# AI 辅助股票分析入门

> AI 可以帮你学习股票研究框架，但不能替你做买卖决策。

本节只讨论如何用 AI 辅助理解公司，不提供任何投资建议、买卖建议或收益承诺。

<PaywallBlock title="股票分析入门完整课程" plan="高级版或以上">

## 1. 公司研究五个问题

| 问题 | 目的 |
| --- | --- |
| 公司靠什么赚钱？ | 理解商业模式 |
| 行业处在什么周期？ | 理解外部环境 |
| 财务质量如何？ | 看收入、利润、现金流 |
| 估值贵不贵？ | 理解市场预期 |
| 最大风险是什么？ | 避免只看优点 |

## 2. 股票研究 Prompt

```text
请做我的公司研究助理。
我想学习研究【公司名称】。

请输出一份研究框架：
1. 公司主营业务
2. 收入来源
3. 所在行业关键变量
4. 需要重点看的财务指标
5. 主要竞争对手
6. 可能的增长逻辑
7. 主要风险
8. 我需要进一步查证的数据来源

请明确说明：哪些内容只是分析框架，哪些需要实时数据核验。
```

## 3. 不要让 AI 直接判断买卖

不要问：

```text
这只股票能不能买？
```

更好的问法：

```text
请列出研究这家公司前必须回答的 10 个问题。
请按商业模式、财务质量、估值、风险四类组织。
```

## 4. 风险清单

```text
请帮我从反方角度分析这家公司。
要求：
1. 列出 5 个可能导致投资逻辑失效的风险。
2. 每个风险对应需要跟踪的指标。
3. 哪些风险是短期噪音，哪些可能是长期问题。
```

::: warning 投资风险
AI 可能会使用过时信息或错误数据。任何公司研究都必须核验公告、财报、交易所信息和可靠数据源。
:::

## 本节练习

选择一家熟悉的上市公司，让 AI 生成研究问题清单。只做学习研究，不做买卖判断。
