# 商业机会的 AI 扫描方法

> 好机会不是"看起来很热"，而是有明确人群、真实痛点、可到达渠道和可持续交付能力。

AI 可以帮你把灵感变成待验证的机会清单，但不能替你完成真实用户验证。

## 1. 机会筛选五问

| 维度 | 问题 |
| --- | --- |
| 人群 | 谁最痛？是否能清楚描述出来？ |
| 痛点 | 现在他们怎么解决？哪里不满意？ |
| 支付 | 他们愿意为更好方案付多少钱？ |
| 渠道 | 你能在哪里触达他们？ |
| 能力 | 你是否有资源交付这个方案？ |

## 2. 机会生成 Prompt

```text
请做我的商业机会分析师。

我的背景和资源：
【行业经验、技能、人脉、资金、时间】

我关注的方向：
【方向】

请生成 10 个小型商业机会。
每个机会包括：
1. 目标人群
2. 具体痛点
3. 现有替代方案
4. 可能的产品/服务形态
5. 获客渠道
6. 验证难度 1-5
7. 最大风险
```

## 3. 机会评分表

| 机会 | 痛点强度 | 支付意愿 | 获客难度 | 交付难度 | 总评 |
| --- | --- | --- | --- | --- | --- |
| 机会 A | 高/中/低 | 高/中/低 | 高/中/低 | 高/中/低 |  |

## 4. 用户验证 Prompt

```text
请帮我设计一次用户访谈。
我要验证的机会是：【描述机会】
目标用户是：【描述人群】

请输出：
1. 访谈前假设
2. 10 个不诱导用户的问题
3. 哪些回答代表需求真实
4. 哪些回答只是礼貌支持
5. 访谈后如何判断是否继续
```

::: tip 判断标准
不要问"你会不会买"，多问"你现在怎么解决、花了多少钱、哪里最痛、上一次发生是什么时候"。
:::

## 即用 Prompt 模板

**市场空白扫描：**
```
请针对「[行业/细分领域]」，帮我列出：
1. 用户最常抱怨但目前没有好解决方案的 3-5 个痛点
2. 现有产品/服务的主要缺口在哪里
3. 在中国市场，国外已有但国内还没人做好的机会方向

输出要求：每条给出具体例子，不要泛泛而谈
```

**需求验证：**
```
我发现了一个潜在机会：[描述你的发现]

请帮我：
1. 判断这是真实需求还是伪需求（从用户行为角度）
2. 列出 3 个可以用来验证这个需求是否真实存在的方法
3. 如果这个需求是真实的，潜在市场规模大概是什么量级
```
