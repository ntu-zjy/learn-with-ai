# AI 时代的终身学习框架

> 终身学习不是永远焦虑地追热点，而是建立一套能持续更新自己的系统。

AI 时代，知识更新变快，但普通人最需要的不是追每个新名词，而是形成“选题、学习、实践、复盘、迁移”的循环。

<PaywallBlock title="终身学习框架完整课程" plan="高级版或以上">

## 1. 终身学习五步循环

| 步骤 | 问题 | 产出 |
| --- | --- | --- |
| 选题 | 我为什么要学它？ | 学习目标 |
| 建图 | 这门知识由什么组成？ | 知识地图 |
| 实践 | 我能用它做什么？ | 小项目 |
| 复盘 | 哪里没学会？ | 错误清单 |
| 迁移 | 它能用到哪里？ | 新场景 |

## 2. 选题 Prompt

```text
请做我的终身学习教练。
我的背景是：
【年龄、职业、经验、当前困惑】

我想学习的方向有：
【列出方向】

请帮我判断：
1. 每个方向和我未来 3 年目标的关系。
2. 学习投入和可能收益。
3. 入门路径。
4. 适合做的第一个小项目。
5. 哪个方向最适合先学 30 天验证。
```

## 3. 30 天学习框架

```text
请为【学习主题】设计 30 天学习计划。
要求：
1. 第 1 周建立地图。
2. 第 2 周学习核心概念。
3. 第 3 周做一个小项目。
4. 第 4 周复盘和迁移。
5. 每周都要有一个可展示产出。
```

## 4. 反焦虑原则

- 不追每个热点，只追和你目标相关的能力。
- 不收藏过量资料，每周只深学一个主题。
- 不只听课，必须做出一个作品或决策框架。
- 不只总结成功，也总结放弃某个方向的理由。

## 本节练习

列出你未来 3 年最重要的 3 个目标。让 AI 帮你反推出最值得学习的 3 项能力，并选一个做 30 天验证。
