# AI 辅助商业计划书

> 商业计划书不是把愿景写得宏大，而是把关键假设、证据和风险讲清楚。

AI 可以帮你搭结构、补问题、检查逻辑，但商业判断必须来自真实市场和用户验证。

<PaywallBlock title="商业计划书完整课程" plan="高级版或以上">

## 1. 商业计划书七个模块

| 模块 | 要回答的问题 |
| --- | --- |
| 用户 | 谁有这个问题？ |
| 痛点 | 现在痛在哪里？ |
| 方案 | 你提供什么更好方案？ |
| 市场 | 规模和增长从哪里来？ |
| 竞争 | 为什么你能赢一部分？ |
| 财务 | 如何赚钱，成本在哪里？ |
| 风险 | 哪些假设可能错？ |

## 2. 计划书生成 Prompt

```text
请做我的商业计划书顾问。
项目想法：
【描述想法】

请先不要写成漂亮文案。
请帮我生成一份商业计划书骨架：
1. 核心用户
2. 用户痛点
3. 解决方案
4. 商业模式
5. 市场验证方式
6. 竞争与替代方案
7. 财务假设
8. 关键风险
9. 还缺哪些证据
```

## 3. 假设检查

```text
请把这份商业计划拆成“已验证事实”和“待验证假设”。
对每个待验证假设，给出最低成本验证方法。

计划书内容：
【粘贴内容】
```

## 4. 一页纸版本

真正有用的计划书，先能压缩成一页：

```text
一句话项目：
目标用户：
最痛问题：
解决方案：
为什么现在：
如何获客：
如何收费：
最大风险：
下一步验证：
```

## 本节练习

把一个商业想法写成 200 字，交给 AI 拆成七个模块。重点看它指出了哪些“还缺证据”的地方。
