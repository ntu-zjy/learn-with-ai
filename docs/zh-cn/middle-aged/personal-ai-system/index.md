# 打造你的个人 AI 助手系统

> 个人 AI 系统不是装很多工具，而是让信息、任务、知识和复盘形成稳定流动。

这一节帮助你把 AI 从"临时问答"变成长期助手。

## 1. 四类助手

| 助手类型 | 负责什么 |
| --- | --- |
| 信息助理 | 摘要、分类、提炼重点 |
| 决策助理 | 列选项、找风险、做对比 |
| 学习助理 | 解释、出题、复盘 |
| 写作助理 | 提纲、修改、风格统一 |

## 2. 个人助手总 Prompt

```text
你是我的长期 AI 助手。
我的工作和学习重点是：
【描述领域】

请遵守：
1. 不直接替我做重大决策。
2. 每次回答都先明确目标和假设。
3. 涉及事实和数据时标出需要核验的地方。
4. 输出要有下一步行动。
5. 如果我的问题模糊，先追问。
```

## 3. 每周工作流

| 时间 | 动作 |
| --- | --- |
| 周一 | 让 AI 帮你拆本周 3 个重点任务 |
| 周三 | 把会议、阅读、灵感整理成行动清单 |
| 周五 | 让 AI 帮你复盘成果和阻碍 |
| 周末 | 整理知识卡和下周问题 |

## 4. 决策检查 Prompt

```text
我正在考虑一个决策：
【描述决策】

请帮我：
1. 列出可选方案。
2. 分析每个方案的收益、成本和风险。
3. 找出我可能忽略的信息。
4. 设计一个低成本验证动作。
5. 不要替我做最终决定。
```

## 本节练习

选择一个你每周重复出现的任务，设计一个固定 Prompt，让 AI 每周按同一格式帮你处理。
