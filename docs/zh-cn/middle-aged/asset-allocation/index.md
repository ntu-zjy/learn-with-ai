# AI 助力资产配置思考

> 资产配置不是追逐收益最高的资产，而是让资金安排匹配你的目标、期限和风险承受能力。

AI 可以帮助你学习框架、整理问题和模拟情景，但不能替你承担金融决策后果。

<PaywallBlock title="资产配置思考完整课程" plan="高级版或以上">

## 1. 资产配置五个变量

| 变量 | 要问的问题 |
| --- | --- |
| 目标 | 这笔钱为了什么？养老、教育、买房、备用金？ |
| 期限 | 多久不能动用？ |
| 风险 | 最大能接受多少波动或亏损？ |
| 流动性 | 需要多快变现？ |
| 再平衡 | 什么时候调整比例？ |

## 2. 个人情况梳理 Prompt

```text
请做我的资产配置学习教练。
注意：不要给具体买卖建议。

我的情况：
年龄：
收入稳定性：
家庭责任：
已有资产类别：
未来 3-5 年目标：
可承受波动：

请帮我：
1. 梳理需要先回答的问题。
2. 解释不同资产类别的基本作用。
3. 给出资产配置学习框架。
4. 列出我需要咨询专业人士的问题。
```

## 3. 情景压力测试

```text
请帮我做资产配置情景分析。
假设出现以下情况：
1. 收入减少 30%
2. 市场下跌 20%
3. 家庭出现大额支出

请分析我需要提前准备哪些安全垫和调整原则。
不要推荐具体产品。
```

## 4. 再平衡思路

再平衡不是频繁交易，而是定期检查：

- 资产比例是否偏离目标太多。
- 风险是否超过承受范围。
- 生活目标是否发生变化。
- 是否需要提高现金储备。

::: warning 决策边界
资产配置涉及个人财务安全。AI 可以帮助学习和梳理问题，但具体方案应结合专业建议和自身情况。
:::
