# 用 AI 快速了解一个行业

> 了解行业不是背一堆报告结论，而是看清楚：谁付钱、谁交付、谁受益、谁承担风险。

AI 可以帮你快速搭出行业研究框架，但事实和数据仍然需要回到可靠来源核验。

## 1. 行业研究五问

| 问题 | 你要看什么 |
| --- | --- |
| 这个行业解决什么需求？ | 客户痛点和付费动机 |
| 钱从哪里来？ | 收入模式和利润来源 |
| 产业链有哪些角色？ | 上游、下游、渠道、平台 |
| 竞争壁垒是什么？ | 技术、渠道、品牌、资质、规模 |
| 最大风险是什么？ | 政策、周期、替代品、成本 |

## 2. 行业入门 Prompt

```text
请做我的行业研究助理。
我要快速了解【行业名称】。

请输出：
1. 这个行业解决的核心需求。
2. 产业链上游、中游、下游分别是谁。
3. 主要商业模式和收入来源。
4. 头部公司或典型玩家类型。
5. 近 3 年需要关注的变化方向。
6. 我必须核验的关键数据清单。

请区分"常识判断"和"需要查证的数据"。
```

## 3. 不要只看结论

AI 生成的行业总结只是第一版地图。接下来要做三件事：

1. 找 2-3 份可靠报告或官方资料核验关键数据。
2. 找 5 家典型公司，看它们产品和客户是谁。
3. 找 10 条真实用户评价或从业者访谈，观察痛点是否真实。

## 4. 输出模板

```text
行业名称：
核心需求：
主要客户：
产业链结构：
收入模式：
关键变量：
代表公司：
主要风险：
下一步要核验的问题：
```

选择一个你感兴趣的行业，用 AI 生成行业地图。然后至少用一个外部来源核验其中 3 条关键判断。

## 即用 Prompt 模板

**行业结构分析：**
```
请用波特五力模型分析「[行业名称]」行业：
1. 现有竞争者（主要玩家、竞争强度）
2. 新进入者威胁（进入壁垒高低）
3. 替代品威胁（有哪些替代方式）
4. 供应商议价能力
5. 买方议价能力

输出格式：每个维度给出评级（高/中/低）+ 1-2句核心判断 + 1个关键证据
```

**信息压缩摘要：**
```
以下是一篇行业报告/新闻，请帮我提炼：
1. 最重要的行业信号（1-2条）
2. 对「[你的公司/业务]」的潜在影响
3. 需要关注的风险点

[粘贴原文]
```
