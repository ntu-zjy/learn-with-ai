# 用 AI 读懂财报

> 财报不是数字堆砌，而是一家公司经营质量的长期记录。

AI 可以帮你解释概念、整理指标和发现异常，但原始数据必须来自公司公告或可靠财务数据库。

## 1. 三张表看什么

| 报表 | 核心问题 | 关注点 |
| --- | --- | --- |
| 利润表 | 公司赚不赚钱 | 收入、毛利率、费用、净利润 |
| 资产负债表 | 公司家底如何 | 资产质量、负债、应收、存货 |
| 现金流量表 | 利润有没有变成钱 | 经营现金流、投资、融资 |

## 2. 财报初读 Prompt

```text
请做我的财报阅读教练。
我会粘贴一家公司的财报摘要。

请帮我：
1. 用通俗语言解释三张表的主要变化。
2. 找出最值得关注的 5 个指标。
3. 标出异常变化和可能原因。
4. 列出需要继续查证的问题。
5. 不要给投资建议。

财报摘要：
【粘贴内容】
```

## 3. 管理层讨论怎么读

```text
请分析这段管理层讨论。
要求：
1. 提炼管理层对增长的解释。
2. 区分事实、解释和承诺。
3. 找出模糊表达。
4. 给出需要用财务数据验证的点。

文本：
【粘贴内容】
```

## 4. 财报问题清单

读完一份财报，至少回答：

- 收入增长来自价格、销量还是并表？
- 毛利率变化是否可持续？
- 应收账款和存货有没有异常？
- 净利润和经营现金流是否匹配？
- 管理层解释是否能被数据支持？
